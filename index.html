How to judge an ISP with this
  1. Run one test between 8:00 PM and 11:00 PM. Wireless home broadband often looks fine at noon and falls apart in the evening rush.
  2. Test next to the router, then where the TV or laptop will sit. Same result in both spots means the ISP is the limit. A worse result far away means Wi-Fi.
  3. Before signing up somewhere new, run it on a neighbour's connection from the same ISP, in the same building if you can.
  4. Keep the screen on and this tab open. If the phone sleeps, the test stops, because the timings would be wrong.
  5. Your phone stands in for the TV or laptop. Test in the same room, on the same band.
